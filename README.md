# Mesa Abierta – Sistema de Gestión para Comedores Comunitarios

Sistema web para gestionar la **operación** de un comedor: stock, donaciones, menús, raciones servidas, voluntarios y turnos, con reportes exportables y control de acceso por roles.
No es un CRM: no se guardan datos de las personas asistidas, solo la cantidad de raciones por día y por servicio.

- `backend/`: API REST (Node.js + Express + MySQL 8). Instrucciones de base de datos y variables en `backend/README.md`.
- `frontend/`: interfaz web (React + Vite, PWA). Instrucciones en `frontend/README.md`.
